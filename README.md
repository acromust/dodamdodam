# 도담도담

**운전 중에도, 가족의 말이 제때 닿는다.**

도담도담은 가족이 폰 웹에서 남긴 5초 음성 메시지를, 차가 안전한 때를 골라 들려주는 Pleos Connect 앱입니다.
남기는 사람은 "비 올 때", "집 근처에 왔을 때" 같은 순간을 고르고, 차는 그 순간이 오면 직진 중이거나 내비 안내가 없을 때처럼 운전에 방해가 덜한 때를 한 번 더 고릅니다.
운전자는 알림음을 듣고 핸들 재생 버튼을 눌러야 듣습니다. 누르지 않으면 주차할 때 들려줍니다.
운전자가 들었는지, 차가 어디 있는지는 남긴 사람에게 가지 않습니다. 남긴 사람이 받는 것은 운전자가 정차 중에 직접 보낸 답장뿐입니다.

대표 장면: 비 오는 퇴근길, 딸이 엄마 폰으로 "아빠, 비 오니까 천천히 와요. 엄마가 뒷자리 아래 우산 있대요!"를 남깁니다. 차는 몇 초 안에 받고, 핸들을 꺾는 중이면 기다렸다가 직진에서 알림음을 냅니다. 아빠는 핸들 버튼으로 듣고, 주차한 뒤 답장합니다.

---

## 1. 빠르게 체험하기 (서버 없이)

서버에 닿지 않으면 앱 안에 들어 있는 **체험용 예시 메시지**로 흐름을 볼 수 있습니다.

1. APK 설치: `adb install -r -g apk/<팀명>_도담도담_release.apk` (APK 위치는 7장)
2. 앱을 열고 **[켜기]** → 속도·위치 권한 허용 → 내 이름 → 핸들 가운데 버튼 연습 → 듣는 방식 고르기(기본 "버튼 눌러서 듣기") → **[시작]**
3. 앱이 서버에 닿지 않고 저장된 메시지도 없으면, 예시 메시지 6개(수진님·지윤님 이름)로 기다립니다. 화면과 사람 목록에 **"체험용 예시"** 라고 표시됩니다.
4. 아래 "에뮬레이터 조작"대로 출발 → 비(와이퍼) → 배터리 부족 → 주차를 해 보면 순간마다 알림음과 예시 메시지가 나옵니다.

- 예시 메시지는 들음 기록과 답장을 서버로 보내지 않습니다.
- 서버에 닿는 순간 예시는 끝나고 진짜 메시지로 바뀝니다.
- 체험 중과 개발 빌드에서는 보기 쉽게 시간을 줄입니다(주차로 보는 주행 15초, 오래 달림 30초, 메시지 사이 20초). 실제 기준은 3분, 2시간, 1분입니다.

## 2. 실제로 남겨 보기 (서버 연결)

서버 주소: `https://dodamdodam.onrender.com`

1. 차 앱 메인의 **[초대 코드 만들기]**(사람이 있으면 메인 아래 **사람** → **[초대 코드 만들기]**)
2. 차 화면에 QR, 주소, 숫자 6자리 코드가 나옵니다. 폰 카메라로 QR을 찍거나 `dodamdodam.onrender.com`을 열고 코드를 넣습니다. 코드를 넣은 사람만 그 차에 남길 수 있습니다.
3. 폰에서 순간(예: 비 올 때) 고르기 → 5초 녹음 → 듣기·다시 녹음, 날짜, 반복 정하기 → 처음이면 이름 정하기 → **남기기**
4. 검수가 끝나면 차가 몇 초 안에 받습니다. 차 화면 가운데에 "대기 중인 음성 메시지 N개"가 보입니다.
5. 에뮬레이터에서 출발하고 와이퍼를 10초 넘게 켭니다(비 판단).
6. 안전한 때가 되면 **띵동** + "○○님 메시지가 있습니다. 핸들 가운데 버튼을 누르면 바로 들립니다." 화면에는 핸들 버튼 그림이 함께 나옵니다.
7. 안내 뒤 8초 안에 **핸들 가운데 버튼**(또는 화면의 [듣기])을 누르면 재생됩니다. 누르지 않으면 주행 중엔 조용하고, 주차할 때 들려줍니다.
8. 주차(P) 뒤 들은 메시지 화면에서 **[○○님에게 답장]** → 5초 녹음 → 폰의 '내 메시지'에 답장이 도착합니다.

에뮬레이터 조작 (Pleos 가상 콘솔)
- 기어: P → D 출발, 다 달리면 P(주차)
- 속도: 출발 뒤 시속 15km를 한 번 넘겨야 주행 중 알림이 시작됩니다
- 와이퍼: 켜고 10초 넘게 두면 "비 올 때" 순간
- 조향: 30° 넘게 꺾고 있으면 "잠시 후: 조향 중"으로 기다렸다 직진 3초 뒤 알림
- 방향지시등: 달리는 중 켜면 꺼진 뒤 3초까지 기다림
- 배터리 잔량: 15% 아래로 내리면 "배터리 부족할 때" 순간
- 핸들 재생 버튼: `adb shell input keyevent KEYCODE_MEDIA_PLAY_PAUSE`

도움말
- 콘솔 페이지를 연 브라우저 창이 가려지면 신호가 끊길 수 있습니다. 콘솔 창을 보이게 두세요.
- 답장은 에뮬레이터 마이크 입력이 켜져 있어야 녹음됩니다(에뮬레이터 확장 설정의 마이크에서 맥 입력 사용).
- 폰에서 녹음하려면 서버가 https 주소여야 합니다(브라우저 규칙).

## 3. 지금 되는 기능

남기는 사람 (폰 웹, 앱 설치 없음)
- 초대 링크로만 남기기. 운전자가 링크마다 따로 끊을 수 있음
- 처음 들어올 때 내 캐릭터 만들기(닮은 모습 고르기 → 머리·얼굴·옷 바꾸기, three.js 3D 미리보기. 안 되면 2D 그림), 이름, 프로필 사진(선택)
- 만 14세 미만 어린이 프로필: 보호자 폰에서 법정대리인 동의 뒤 만들고, 그 폰에서 어린이가 남김
- 날짜: 오늘, 내일, 날짜 고르기, 30일 동안
- 순간 7가지: 차 탈 때, 주차했을 때, 집 근처에 왔을 때(차 내비에 저장한 집), 고른 장소 근처(지도에서 고름. 카카오 장소 검색, 안 되면 OpenStreetMap 검색), 비 올 때, 오래 달렸을 때, 배터리·기름 부족할 때(에뮬레이터는 전기차라 배터리로 확인)
- 5초 녹음, 반복(한 번만 / 매번)
- 내가 남긴 메시지 지우기, 답장과 이모티콘 반응 받기
- 남길 때 알림: 비 오기 전날 "비 올 때 들을 한마디 남길래요?" (웹 푸시, 실제 폰 알림은 아직 확인 전)

검수
- 욕설, 놀라게 하는 소리, 운전 중 조작을 시키는 말을 막음(Google Gemini API). 애매하면 보류 뒤 다시 검수. 프로필 사진도 같은 방식으로 확인

운전자 (차)
- 차 홈 '우리 가족 광장': 남긴 사람마다 캐릭터가 쿠션에 앉아 있는 3D 장면(Filament). 날씨·밤·문·안전벨트·무드등 같은 차 신호에 반응하고, 주차(P)에서만 움직임. 저사양 모드 있음
- 남기면 차가 몇 초 안에 받음
- 출발 때 짧은 안내 "대기 중인 음성 메시지 N개입니다." 메인 화면은 대기 개수만
- 안전 타이밍: 큰 조향, 달리는 중 방향지시등, 내비 안내·통화·음성비서·알람 소리, 주차장을 벗어나는 중에는 기다림
- 듣는 방식 3가지: 버튼 눌러서 듣기(기본), 바로 듣기, 주차하면 듣기
- 핸들 재생 버튼과 화면 위 알림 카드 [듣기]
- 메시지가 나오는 동안 음악은 잠깐 멈췄다가 다시 이어짐
- 동승자가 있으면 보낸 사람 이름을 말하지 않음(프라이빗 모드)
- 주차할 때 못 들은 메시지 이어서 들려주기
- 정차 중 답장(5초 녹음)과 이모티콘 반응
- 반복 메시지는 주차 때 "다음에도 듣기 / 그만 듣기"
- 지난 메시지 다시 듣기(보관 기간 안)
- 사람 신고(그 사람 초대 링크가 끊기고 남은 메시지도 안 나옴)
- 서버 없이 도는 체험용 예시 메시지
- 차마다 메시지를 나눔(서버 하나를 여러 차가 써도 섞이지 않음)

## 4. 안전·개인정보 원칙

- **안전한 때만**: 순간이 와도 바로 틀지 않습니다. 직진 3초 이상일 때만 알리고, 버튼을 누른 뒤에도 재생 직전에 한 번 더 봅니다.
- **버튼을 눌러야 들음**: 기본은 알림음 뒤 운전자가 눌러야 재생됩니다. "들으시겠어요?"처럼 묻거나 다시 재촉하지 않습니다.
- **양을 줄임**: 주행 중 메시지는 5초 이내, 메시지 사이 1분 이상, 주행 중 하루 5개까지. 넘치면 주차할 때 들려줍니다.
- **주행 중 화면은 최소**: 대기 개수와 듣기 버튼만. 다시 듣기·답장·설정은 정차 중에만.
- **들었는지·위치는 보내지 않음**: 차 신호와 위치 판단은 모두 차 안에서 합니다. 남긴 사람에게는 운전자가 보낸 답장만 갑니다. 운전자가 앱을 닫거나 그만 듣기를 골라도 남긴 사람은 알 수 없습니다.
- **들은 날짜만 기록**: 같은 메시지를 다시 틀지 않으려고 서버에는 들은 날짜만 남기고 시각은 남기지 않습니다.
- **처음 켤 때 고지**: 차 앱 첫 화면에 서버로 가는 것(내 이름, 답장 목소리·이모티콘, 들은 날짜)과 보내지 않는 것(차 위치, 운전 정보)을 적고 개인정보 처리방침을 바로 열 수 있게 했습니다.
- **보관 기간**: 들려줄 기간이 끝나고 30일 뒤 서버가 음성 메시지와 답장을 지웁니다. 남긴 사람은 언제든 자기 메시지를 지울 수 있고, 차에서도 곧 빠집니다.
- **검수**: 남긴 음성 메시지는 차로 가기 전에 검수합니다. 검수 서비스가 안 될 때는 소리 크기만 보고 먼저 보내고, 나중에 다시 검수해 걸리면 뺍니다. 만 14세 미만은 보호자가 법정대리인 동의를 한 어린이 프로필로만 남깁니다.

## 5. 폴더 구성

- `car-app/` 차 앱(Android, Kotlin). Pleos Connect SDK Vehicle·NaviHelper·FusedLocation, 3D 광장은 Filament. 안내 음성은 미리 녹음한 파일(`res/raw`)이고 기기 TTS는 쓰지 않습니다.
- `car-app/tools/` 광장 장면·캐릭터·얼굴 그림·안내 녹음을 만드는 스크립트(원본 폴더는 `DODAM_REFS` 환경 변수로 지정, 원본은 저장소에 넣지 않음)
- `server/` 남기는 사람 웹(`web/`: 화면, 개인정보 처리방침·이용약관·위치정보 이용약관)과 서버(`server.py`), 검수(`moderate.py`), 웹 푸시(`push.py`), 클라우드 보관(`store.py`), `Dockerfile`
- `tests/` 회귀 시험 도구(`reg.py`, `lib.sh`)와 결과 기록(`RESULTS.md`)
- `render.yaml` 클라우드 배포 설정(비밀 값은 적지 않음)

APK 빌드 (JDK 17, Android SDK, Gradle 8 이상 필요)

```
cd car-app
gradle assembleRelease -PapiBase=https://dodamdodam.onrender.com -PshareBase=same -PcarKey=<열쇠>
adb install -r -g app/build/outputs/apk/release/app-release.apk
```

- 개발용은 `assembleDebug`(결과 `app/build/outputs/apk/debug/app-debug.apk`). 개발 빌드만 http 주소(맥 서버)에 붙고 로그를 남깁니다. release는 https 서버만 쓰고 로그를 남기지 않습니다.

- `-PapiBase`: 차가 붙는 서버 주소. 빼면 맥에서 돌린 서버(에뮬레이터에서 `http://10.0.2.2:8090`)
- `-PshareBase`: 초대 링크 앞부분 주소. `same`이면 `-PapiBase`와 같게, 빼면 `http://localhost:8090`
- `-PcarKey`: 서버가 차 전용 주소를 열쇠로 잠갔을 때 넣는 값. 저장소에는 적지 않고 빌드할 때만 넣음
- 세 값을 모두 빼고 빌드하면 서버가 없을 때 바로 체험용 예시 메시지로 돕니다.

서버 로컬 실행 (파이썬 3, ffmpeg 필요)

```
cd server
python3 server.py 8090
```

- 웹은 `http://localhost:8090`, 에뮬레이터 차 앱은 `http://10.0.2.2:8090`으로 닿습니다.
- 선택 환경 변수: `PORT`, `TZ`, `CAR_KEY`, `GEMINI_API_KEY`, `MOD_MODELS`, `MODERATE`, `KAKAO_JS_KEY`, `KAKAO_REST_KEY`, `SUPABASE_URL`, `SUPABASE_KEY`, `SUPABASE_BUCKET`, `VAPID_PUBLIC`, `VAPID_PRIVATE`, `FORECAST`
- 카카오 키가 없으면 지도는 MapLibre + OpenFreeMap(안 되면 Leaflet + OpenStreetMap), 장소 검색은 OpenStreetMap(Nominatim·Photon)으로 돕니다.
- 웹 푸시는 `pywebpush`가 설치돼 있을 때만 켜집니다.

## 테스트 환경 및 필요한 설정

- Pleos Connect Emulator 2.1.0(Android 14, API 34)과 Pleos Connect Virtual Console. 위 '에뮬레이터 조작'대로 기어·속도·와이퍼·배터리를 바꿉니다.
- 앱 설치는 `adb install -r -g`(권한을 미리 허용). `-g` 없이 깔면 첫 실행에서 속도·위치·알림 권한을 묻습니다.
- 서버: 클라우드(`https://dodamdodam.onrender.com`)로 빌드한 APK는 따로 설정할 것이 없습니다. 무료 서버라 한동안 안 쓰면 첫 응답이 늦을 수 있고, 그동안 차 앱은 체험용 예시 메시지로 돕니다.
- 답장 녹음: 에뮬레이터 확장 설정의 마이크에서 맥 입력을 켭니다.
- 폰 웹: https 주소에서 열어야 녹음됩니다. 카카오톡 같은 앱 안 브라우저로 열면 다른 브라우저로 여는 방법을 안내합니다.

## 6. 시험 결과 요약

모두 Pleos Connect 에뮬레이터(Android 14)와 가상 콘솔, 위 서버로 시험했습니다. 맥에서 소리는 내지 않고 오디오 상태와 로그로 판정했습니다. 자세한 내용은 `tests/RESULTS.md`.

- 회귀 시험(11/06, 화면 개편 뒤): 23가지 경우, 확인 항목 57개 모두 통과. 콘솔이 속도를 천천히 줄이는 탓에 시간이 빠듯한 2개(주차장 속도, 정차 중 깜빡이)는 한 번 놓쳤다가 다시 돌려 통과.
